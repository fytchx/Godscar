# Godscar Art Asset Pack — First Pass

This owner-directed concept pack groups art for the five-zone enemy set, five combat biomes, the current ten weapon base types, all distinct equipment/off-hand art categories, and a reusable set of combat/spell effects.

## Pack contents
- **5 biome backgrounds:** vertical combat-scene concepts with the center left relatively open for the combatants and UI.
- **35 monster concepts:** six enemies and one boss for each of five zones.
- **10 weapon icons:** sword, mace, dagger, wand, frost rod, greataxe, scythe, storm spear, staff and bow.
- **11 equipment icons:** shield, spell tome, quiver, helm, chest armor, gauntlets, belt, leg armor, boots, ring and amulet. The ring art covers both ring slots.
- **12 combat/spell effects:** slash, impact, ember, bleed, frost, spirit, aegis, starfall, poison, lightning and shadow cues.

## Status and use
These are concept assets for review, not final production art. All character, equipment and effect WebPs are separate transparent stills; there are no animation frames yet. Backgrounds are standalone vertical images. The pack is not wired into the browser build or any save/gameplay systems. Review the images at actual phone combat size before integrating or commissioning animation.

The full-resolution PNG originals and reference sheets are preserved in the companion concept ZIP. This repository folder contains optimized WebP review copies.
