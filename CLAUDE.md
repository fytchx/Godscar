# Godscar instructions for Claude and other coding agents

Before doing anything, open **[AGENTS.md](AGENTS.md)** and **[START-HERE.md](START-HERE.md)**. For working context, read `docs/PROJECT-STATE.md`, `docs/DECISIONS.md`, `docs/DESIGN-INTENT.md` and `docs/WORKFLOW.md`.

**Current direction:** ORIGINAL browser idle ARPG on `preview/browser`, not the incomplete Godot port on default `main`.

**After every code/config/asset change:** update project state and changelog in the same commit; run tests, commit/push, check deployment and leave a complete handoff. Be candid about scope and uncertainties; ask before implementing unclear design choices. Write code a human can understand. Never touch Arcana.
